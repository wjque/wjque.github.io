# From Similarity to Event Understanding

目前视频生成模型的痛点：生成的视频仅仅是表面的真实性，**并不能理解视频帧之间的差异所表现的物理规律**，希望从图像表征的工作中获得启发：

## 关于图像表示领域的工作综述

在图像生成领域，已经有不少工作实现了让算法理解图像的内容：

- `CLIP`：早期的度量学习方法，能够将文本和图像映射到同一维空间中，**度量文本与图像的相关性**
  - 使用 `ViT` 作为图像编码器，每一个 `patch` 作为一个 `token`，直接通过线性层映射为一个嵌入；文本编码器使用 **Transformer**
  - 都使用 `<EOS> token` 对应的嵌入作为全局的语义表示
- `LLaVA`：将 `CLIP` 提取出来的特征应用到大语言模型当中，是早期对**多模态模型**的探索
  - 用一个轻量化的线性层，直接将 `CLIP` 的特征映射到 `LLM` 输入文本嵌入的维度，作为上下文的一部分
- `MAE`：受到语言模型训练方式的启发，通过**掩码图像**，让模型学习重建被掩码的区域，从而得到图像的嵌入表示
  - 使用编码器-解码器架构，编码器只接受没有被掩码的 `patch`，解码器解码时需要补上相应位置的掩码
  - 和语言模型 `BERT` 一样，只计算掩码部分的重建误差
  - 输入解码器的掩码是共享的、可学习的向量，作用是告诉解码器这个位置的图像是未知的
  - 编码器和解码器的设计是**非对称的**，同为 **Transformer** 结构，但是解码器的嵌入空间维度比编码器更窄，深度远比解码器的更浅，这样做的原因是为了加速训练，同时让编码器能学到更精确的图像表示
- `DINO`：是一项具有里程碑意义的工作，通过自监督式的蒸馏，使用大规模的图像数据进行训练，设计了多种提升训练稳定性的方法，将模型规模扩展到 `7B`
  - 使用 `ViT` 架构，模型输出的嵌入主要包括三部分：`<CLS> token` 对应的嵌入，可以作为图像的全局语义表示；`register tokens` 对应的嵌入，可以作为图像全局语义表示的补充；`patch tokens` 对应的嵌入，可以作为图像局部像素块的特征表示
  - `DINOv1`：教师网络和学生网络初始化为相同的 `ViT` 模型
    - **DINO loss**：使用交叉熵损失，将教师网络的输出作为 **groud-truth**，将 `<CLS> token` 对应的嵌入先经过 **MLP + softmax** 转为原型分数 (`prototype score`)，再做 **element-wise cross-entropy**
    - 为了**避免教师网络坍缩**为永远输出相同的嵌入，需要将教师网络输出的 `<CLS> token` 对应的嵌入减去一个以往历史值指数平均的 **baseline**，再除以一个温度系数（使分布变得更锐利，有助于学习图像级别的语义特征），学生网络的输出只需要除以其自身的温度系数，再经过 **softmax** 即可
    - 教师网络的权重使用学生网络的指数平均，学生网络的权重使用损失函数优化
  - `DINOv2`：优化训练策略，提升数据集质量
    - 使用高质量数据从低质量数据中检索，使用预训练的 `ViT-H/16` 模型度量高质量和低质量数据的相似性，从而检索出高质量的数据
    - 除了图像级别的 `DINO Loss` 以外，还引入了 `Patch Loss` 和 `KoLeo Loss`
      - **Patch Loss**：鼓励模型学习局部特征表示，学生网络的输入随机掩码一部分 `patch`，教师网络不做掩码，将输出的 **mask patch emb** 分别经过各自的 **MLP + softmax** 转为原型分数，计算交叉熵损失（论文中的 **iBOT Head** 指的就是教师和学生各自的多层 **MLP**）
      - **KoLeo Loss**：作为正则项避免模型的全局特征表示坍缩，鼓励模型用不同维度表示图像信息，具体计算方法是遍历同一个 **Batch** 所有样本的全局特征 (`<CLS> token` 对应的输出)，取每一维特征距离最近的两个样本之间的距离，取对数后求和，目标是最大化这个距离
    - 将教师网络的输出从 **Softmax-Norm** 转为 **SK-Norm**
      - 教师网络的输出首先仍然会经过一个可学习的 **MLP**，经过低温锐化后，使用**辛克宏-诺普中心化**，将输出转化为一个双随机矩阵（沿特征维度求和，结果为 1，沿批维度求和，结果也为 1），有利于利用更高维的原型空间，并且让样本间的分布也变得合法
      - 学生网络是处理方法和 `DINOv1` 中一样，只进行简单的低温锐化（复杂的分布拟合需要交给模型内部实现）
    - 引入高分辨率图像后训练策略，在训练后期阶段使用较高分辨率的图片
  - `DINOv3`：进一步规模化，提出 `Gram Anchoring` 解决长时间训练下局部特征相似性坍缩的问题
    - **Gram Anchoring**：冻结预训练一定阶段的模型，作为 **Gram Teacher**，输出图像特征的 `Gram Matrix`（不同 `patch tokens` 之间的余弦相似度矩阵），直接与学生网络的 `Gram Matrix` 求 **F 范数**（就是把矩阵拉长为一个向量，直接求这个向量的长度），作为 $\mathcal{L}_{Gram}$
    - **register token**：研究发现图片背景的特征往往具有较大的范数，这导致图片的全局特征更多被这些背景信息影响，研究者认为是因为所使用的嵌入维度不足以表示整张图片的全局信息，导致模型将部分全局信息存储至信息量较低的背景部分的嵌入中，所以在 `patch token` 之前加入 `register token`，吸收背景的范数，这些 token 不具有时间嵌入，只参与计算

直接用全局特征的余弦相似度我们就可以判断两张图片的相似性，使用局部特征的余弦相似度可以实现多张图片之间的目标跟踪，这些特征可以用来度量**图像与图像之间的相似性**，让模型能够**从像素空间的理解跃迁到特征空间的理解**（像素空间距离小不一定相似，特征空间距离小一定相似）

这种特征只能表示哪些图片是相似的，以及图片中的哪些区域是相似的，对于图像理解任务来说，这种功能已经是足够的，无论是图像分类、图像检测、图像分割，都可以通过在这些基座模型的基础上进行微调（纯零微调 / 线性探测器微调 / 适配器微调 / 全量微调），进而完成这些任务

但对于视频理解任务而言，仅仅判断视频之间帧与帧之间相似性是没有多少意义的，例如没有办法根据相似性判断视频中发生事件的相似性，必须让模型能够**理解视频中发生的事件**，进而能**预测视频将会发生的事件**，这才具有实际的意义，这也是世界模型所要做的

但正如仅仅依靠上面的视觉基础模型也无法实现让模型理解图像的语义，必须引入一定的微调才能让模型掌握从特征空间进一步映射到语义空间的能力，视频理解模型应该也需要经过这一阶段，从**判断事件的相似性**，到**微调理解事件的语义**，进而**从语义预测事件的发生**

这个模型最直接的应用应该就是自动驾驶，需要预测危险发生的可能性，进而采取行动避免危险的发生（例如经过有遮挡的路口时主动降速，确认路口没有人探出后再加速行驶）
