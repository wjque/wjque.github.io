# DINO 特征表示与应用

### DINO

使用百万级别的无标注数据对 `ViT` 进行自蒸馏（`student-teacher` 架构），证明了自监督学习在**图像语义提取**和**局部特征表示**任务上的可行性

技术细节
- **DINO loss**: 取输出中 `<CLS> token` 对应的嵌入作为全局的语义表征，将学生网络和教师网络的输出分别经过独立的 MLP 层（输出维度通常为 65536），得到 **prototype score** (原型分数)，算学生网络和教师网络原型分数的交叉熵损失
  - 教师网络的输出需要减去一个随训练步数**指数滑动平均的中心值**（防止教师模型对所有样本都输出相同结果，导致训练失败，这称为 `Collapse`），并除以一个**温度系数**（锐化单样本原型分数的分布，让主要的原型变得更重要，也是为了避免 `Collapse`），最后经过一个 `softmax` 层输出原型概率
  - 学生网络的输出只需要除以其自身的温度系数，再经过 `softmax` 转为原型概率
- 教师网络权重的更新使用学生网络的**指数滑动平均** (EMA)

### DINOv2

使用 `iBOT` 损失在 `Patch-Level` 进一步细化模型的局部特征表示准确性，将特征表示维度从 `768` 增加至 `1024`，设计了一系列方法提高训练的稳定性，保证全局特征不坍缩

技术细节
- **iBOT loss**: **随机掩码**图像中的部分 `Patch`，取这些 `Patch token` 对应的嵌入作为局部特征表示，计算教师网络和学生网络的交叉熵损失
  - **DINO loss** 和之前是一样的，先经过几层 `MLP` 再做 `softmax`，区别在于中心化方式
  - **Sinkhorn-Knopp centering**：将教师网络的输出经过几次快速矩阵运算转换为**双随机矩阵**（每行的和约为 1，每列的和约为 1，行表示特征向量，列表示批量大小），学生网络的输出仍然使用之前的 `softmax` 中心化处理，这一方法的引入是为了兼顾 **Patch-Level** 和 **Image-Level** 的分布稳定性
- **KoLoe loss**: 每一个样本都会有一个表示**全局语义的特征向量**（`<CLS> token` 对应的输出），遍历批次内所有样本的特征向量，计算它和**同一个批次内其他样本**（不包括该样本）特征向量**最小的欧氏距离**，对批次大小取均值，目标是**最大化**这个损失函数，这个方法避免了模型只用少数几维特征对图像进行表征，导致**全局特征学习坍缩**

### DINOv3

进一步扩大模型的规模，参数量达到 `7B`，使用的数据高达 `170M`，核心贡献是提出了 `Gram Anchoring` 方法，解决了模型在长时间训练的情况下导致的**局部特征相似性坍缩**问题

技术细节
- **Gram Anchoring**: 对网络输出的局部特征表示，记为 $X\in\mathbb{R}^{N\times d}$，定义 Gram Matrix 为 $G=XX^T$

  其中每一个 `patch token` 对应的输出默认已经过归一化，每个元素表示 `patch` 间的余弦相似度，作为正则项帮助模型**学习稠密的局部图像特征**
  - **Gram Teacher**: 早期训练的模型快照，完全冻结，用于提供锚定的 **Gram Matrix**
  - **Teacher (EMA)**: 学生网络权重的指数平均
  - **Student**: 主要更新的网络
  - 使用了**四个损失函数**对网络进行优化：$L_{DINO},L_{iBOT},L_{KoLeo},L_{Gram}$
- **register tokens**: 实验过程发现背景部分对应的特征向量有较高的 `L2` 范数，这意味着它们对 `<CLS> token` 的影响较大（自注意力机制），研究人员认为这种现象发生的原因是 `<CLS> token` 不足以存储全局语义信息，而前景物体本身具有较为丰富的局部信息，所以模型会将部分全局信息存储到信息量较低的背景区域，为了解决这个问题，研究人员向输入最前端加入了 **4 个可学习、无位置编码的寄存器令牌**，用于降低背景特征向量的 `L2` 范数，提高稠密特征提取的性能

### DINO 模型的应用

#### True Zero Finetuning

- 图像检索 / 去重 / 相似度比对：直接使用原生输出 `cls_tokens` 作为整张图的全局特征向量
- 跨图像稠密特征对应：直接用不同图像的 `patcch_tokens` 做相似度匹配，能得到**像素块级**的稠密对应
  - 多视角图片物体位置对齐 / 视频像素块追踪（目标跟踪）
  - 非刚性物体匹配
- 单图前景物体粗分割：直接对图像的 `patch_tokens` 做 `k-means` 聚类（k=2/3），再映射回原像素区域，可得到粗粒度的物体掩码

#### Linear Probing

指的是在模型输出端加入一个极小的可训练线性探测器 (Linear Probe)，冻结骨干模型，对线性层做简单的监督微调

纯零微调可以实现的，使用线性探测头也都能实现，并且能进一步强化功能

- 图像检索与重识别：融合所有 `tokens` 对应的嵌入，训练线性层将融合特征映射到**低维检索空间**，示例场景：商品名-商品图检索、文物名-文物图检索（类似 `CLIP` 的功能，但文本空间的维度比图像空间的维度更低）
- 图像分类：使用 `<CLS> token` 或 `Avg(<CLS> token + patch tokens)` 作为图像的表征，训练一个线性分类器
- 语义分割（稠密任务）：使用 `patch tokens` (或结合 `register tokens`) 做线性投影 + 上采样，输出**像素级别预测**
- 单目深度估计：以 `patch tokens` 为基础特征，融合 `register tokens` 的全局特征，训练线性回归层预测深度值
- 视频追踪：通过帧间 `patch` 特征匹配（也可以用 `register tokens` 增强特征的稳定性），经过线性层 + 上采样，能够实现像素级的追踪，并且在有遮挡的场景中表现优异
- 目标检测 / 实例分割：这项任务有较为丰富的实现形式，最主流的是使用 `MaskDINO` 作为输出端模块，仍然冻结主干 `DINOv3`
  - 值得注意的是，此时仅使用 `patch` 级别的特征，并且需要改造 `DINOv3` 的输出，将最后四层 `Transformer` 输出的所有 `patch tokens` 都输出
  - `MaskDINO` 由两个部分组成：**Mask DINO Transfromer Encoder & Mask DINO Transformer Decoder**，输出有两个 `Head`（一般为几个线性层），一个用于输出目标中心位置和类别（目标检测），另一个用于输出实例分割的 `mask` (和原图像统一尺寸)
